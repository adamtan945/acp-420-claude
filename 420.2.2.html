3 分鐘速覽

SLA＝名稱＋條件＋目標＋calendar

  1. ConditionsStart（開始計時）、Pause（暫停，選填）、Stop（停止）；多個條件任一符合就生效。
  2. Goals每個 goal＝JQL（哪些 work item）＋time target＋calendar；由上而下比對，第一個符合的生效。
  3. Calendar時區、工作日、時段（可多段，例如扣掉午休）、假日；預設 09:00–17:00。
  4. Priority 分組Goal 下可加 priority，每個 priority 各自的 target；All remaining priorities 兜底；最多 90 個 goal。
  5. 名稱建好就不能改所以要取清楚的名字，例如 Time to first response。
  6. 新 SLA 套到所有 work item包含已關閉的；編輯後進行中的 cycle 會重算或被丟棄。

Goals

由上而下比對的目標

  • Space settings → Request management → SLAs → Add SLA（或 Edit）。
  • Goal 依清單由上而下比對 JQL，第一個符合的 goal 生效；最後一個 goal 通常是「All remaining work items」兜底。
  • 沒有任何 goal 符合的 work item 就沒有這個 SLA（queue 看不到時鐘）；兜底的 All remaining 設成 No target 時也一樣不會顯示。
  • 每個 SLA 最多 90 個 goal；在 goal 下用 Add priority 分組，每個 priority 各自的 target，仍只算 1 個 goal。All remaining priorities 會接住其他 priority（含 None）。
  • Priority 改變時，已計時間沿用、剩餘時間依新 priority 的目標重算，SLA 不會重新開始。
  • 不同區域或時區：用 custom field 分 goal，各 goal 選不同 calendar。
  • 可以用 customer／organization detail 寫 goal 的 JQL（例如 Platinum 客戶目標較短）。
避免

官方：同一個人同時是 reporter 與 assignee，SLA 可能算不準。Goal 下已用 priority 分組時，不要在 JQL 再寫 AND priority = …，會重複。

不會。已經計算的時間會算進新目標。
本段必考
  • 由上而下，第一個符合的 goal 生效。
  • 沒有 goal 符合＝沒有 SLA。
  • 最多 90 個 goal。
Calendar

工作時段

  1. 建立SLAs 頁右上 calendar 圖示 → Add calendar → 名稱與時區。
  2. 工作日與時段勾選工作日、每天加時段；按 ＋ 可在一天內加多段（例如午休前後）。
  3. 假日加入國定假日；假日不計時。
  4. 套用在 goal 的 Calendar 欄位選它。新建 calendar 時時段預設帶入 09:00–17:00；goal 若選 24/7 calendar 則全天候計時。
本段必考
  • Calendar 決定「什麼時候」算時間；pause 決定「什麼狀態」不算。
編輯的影響

改 SLA 之後會怎樣

Cycle 狀態改設定之後
已完成的 cycle不變；新條件會重開它時，系統另開新 cycle
進行中的 cycle依新設定重算；可能繼續、或被丟棄（新的 start／stop 對不上過去任何事件）
過去發生的事件不會因為新的 stop 條件補產生已完成 cycle
SLA 名稱不能改（建立時就要取好）
本段必考
  • 新 SLA 套用到所有 work item（含已關閉）。
  • 改 SLA 不會改寫已完成的 cycle。
排查

SLA 不見或不對

症狀先查
某些 request 沒有 SLA 時鐘沒有任何 goal 的 JQL 符合；或沒有 start 事件發生
夜間也在扣時間Goal 用的是 24/7 calendar，或 calendar 時區錯
等 customer 回覆時還在計時沒有設 pause on Waiting for customer
首次回覆後 SLA 沒停Stop 用的是 Resolved；首次回覆應該用 Comment: For customers
VIP 的目標沒生效VIP goal 排在「All remaining」之後；把較具體的 goal 往上移
改了 stop 條件後時鐘消失新的條件對不上過去事件，進行中的 cycle 被丟棄
本段必考
  • Goal 順序：具體的放上面，兜底的放最後。
