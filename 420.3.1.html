Assets

Assets 記錄公司有哪些設備、服務、合約與它們的關係。考試只考「會用」：認得名詞、在 request 引用 object。

3 分鐘速覽

會用、不會設：Assets 給工單加上「哪台、哪個、誰的」

  1. 考綱明說只考使用Utilize, but not configure：認得 schema、object type、object、attribute，會在 request 裡引用它們。
  2. 四層Object schema → object type → object → attributes。
  3. Object schema一組相關資料（例如 IT 資產）；有自己的權限。
  4. Object type同類 object 的群組（Laptop、Server）；可有 parent／child、繼承 attributes、可設 abstract。
  5. Assets object 欄位Jira 的 custom field，讓 request 連到 object；雙向連結，object 頁看得到相關 work item。
  6. 在哪用Request type 表單、forms、queue 欄位、JQL、automation（AQL）。
四層模型

Schema、type、object、attribute

名詞是什麼例子
Object schema一組相關資料的容器，有自己的權限設定IT Assets、Software Registry、Business Portfolio
Object type同類 object 的群組；可設 parent／child 與繼承；abstract 型別不能放 objectHardware（abstract）→ Laptop、Server
Object具體的一筆資料MacBook-0042、db-prod-01
Attribute描述 object 的欄位：文字、數字、狀態、日期、使用者、reference（連到另一個 object）Owner、Serial number、Status、Vendor
預設 attributes每個 object 都有：Name、Key（不能改）、Created、Updated（另有 Display name）Key 例：ITA-123

Laptop object type 的一個 attribute；如果 Vendor 是另一個 object type，它就是 reference attribute。

  • Schema → type → object → attribute。
  • Reference attribute 把 object 串起來。
在 request 引用

Assets object 欄位

  • Assets object 是一種 Jira custom field；建立與編輯要 Jira 授權（通常由 Jira admin 建、加到 screen 與 request type）。
  • 加進 request type 的表單後，customer 提單時就能選「哪一台電腦」「哪個系統」。
  • 連結是雙向的：work item 上看得到 object，object 頁看得到所有相關的 work item（追根因、評估變更影響）。
  • 欄位設定有三種過濾：Object schema（必填）、Filter scope（AQL）依 Assets 資料過濾、Filter work scope（AQL）依目前 work item 的其他欄位過濾（可做連動選單，例如先選 Manufacturer 再選 Model）。
  • Filter work scope 可用 placeholder，例如 objectType = "Laptop" AND Owner LIKE ${reporter.label}：只列出提單人自己的筆電；可勾 Display a default object in the customer portal。
  • 也可以放在 forms、當 queue 的欄位、用在 automation（Lookup objects、Edit object）。
  • 限制：Assets object 欄位不能拿來在 JQL 排序（ORDER BY）。
考題長相

「agent 處理 request 時要看到受影響的伺服器，並在伺服器頁看到它所有的 incident」→ 在 request type 加 Assets object 欄位。

本段必考
  • Assets object 欄位＝雙向連結。
  • Filter scope 依 Assets；filter work scope 依目前 work item（可用 placeholder）。

考題愛用的錯誤說法

Abstract object type 可以直接建立 object。
Abstract 型別不能放 object，只把 attributes 傳給 child。

Object 的 Key 可以改。
Key 由 schema key＋數字組成，不能改。
官方來源
在 work item 加 object 只是單向記錄。
會建立雙向連結，object 頁看得到相關 work item。

可以用 Assets object 欄位在 JQL 排序結果。
Cloud 不支援用 Assets object 欄位排序搜尋結果。

Filter scope（AQL）可以用 ${reporter} 這類 placeholder。
Placeholder 只能用在 Filter work scope。
