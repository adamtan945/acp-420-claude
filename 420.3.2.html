3 分鐘速覽

Service：讓 incident 與 change 知道「影響到誰」

  1. Service 是全站的跨所有 service project 使用；考試版在 Features 開 Services（只有 ITSM project）。
  2. 每個 service 有Tier、owner team、change approvers、responders、stakeholders、references（依賴其他 service）、type（只是分類）。
  3. Tier 1–4Tier 1 最關鍵；可當 automation 與 alert 的條件。
  4. Affected services 欄位把 service 加到 incident、change；從 graph 看上下游。
  5. 加了 service 不會自動通知或改 priority要通知 owner team 就加 responder；priority 跟 tier 走要寫 automation。
  6. 現行底層是 AssetsSoftware Registry 與 Business Portfolio 兩個 schema；權限看 Assets schema。
Service 的組成

一個 service 設定什麼

屬性用途
Tier多關鍵：Tier 1 失效重大影響 customer 或營收；Tier 4 幾乎無感
Owner team負責的團隊；它的 on-call schedule 會顯示在 service 頁
Change approvers這個 service 的 change 要誰核准
RespondersService 出事時被通知的人或 team
Stakeholders不直接處理、但要知道 incident 進度的人
References／relationships依賴哪些 service（Depends on），用來推算影響範圍；每個 service 最多 100 個
Type分類標籤，沒有技術影響
本段必考
  • Tier＝關鍵程度；references＝依賴。
  • Type 只是標籤。
日常使用

在 incident、change、request type 用 service

  1. 啟用考試版：Space settings → Features 開 Services（只有 ITSM project，非 ITSM 不提供）。現行：側欄 Operations → Services。
  2. 建立與設定建 service、設 tier、owner team、change approvers、responders、stakeholders、references。
  3. 加到 request type在 incident、change 的 request type 加 Affected services（或 Service）欄位，讓提單人或 agent 選受影響的服務。
  4. 在 work item 加／移除打開 incident 或 change → Affected services 欄位加入或按 Remove 移除；沒有 Jira 授權的人看不到這個欄位。
  5. 看影響Incident 頁顯示上游（它依賴的）與下游（依賴它的）service。
  6. 自動化Automation 的 Affected services condition：例如 Tier 1 service 受影響時寄信給主管、或把 priority 設成 Highest。
不會自動發生的事

官方：把 service 加到 incident 不會自動通知 owner team、也不會依 tier 設 priority。要通知就把 owner team 加成 responder；要依 tier 設 priority 就寫 automation rule。

本段必考
  • Service 加到 incident 不會自動通知或改 priority。
  • Tier 可當 automation／alert 的條件。
權限

誰能改 service

  • Service 是 Assets 的 object：權限由 Assets schema（global、schema、object type 三層）決定，不是 JSM project role。
  • 編輯 service、管理 references、換 owner team、刪除、改 attribute 都要該 schema 的編輯權限。
  • 兩個預建 schema：Software Registry（技術服務：Applications、Capabilities、Software Services、Deployed Services）與 Business Portfolio（Business Services）。
本段必考
  • 看得到但不能改 → 查 Assets schema 權限。
