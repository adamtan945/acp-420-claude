420.4.2・Customer Facing Features 21%

Forms

Forms 讓表單能排版、依答案顯示不同區塊，不用請 Jira admin 建一堆 custom field。考你建立、條件、連結 Jira field、放的位置與送出後的行為。

考試佔 21%
官方考綱原文（這一節會考的範圍）
  • Create a form using a blank form or template (structure the form with bullets, tables, quotes, and layouts).用空白或 template 建表單並排版
  • Organize forms using sections and conditional logic.用 section 與條件邏輯組織表單
  • Configure form fields behavior, including default response and linked Jira fields.設定欄位行為：預設回答、linked Jira fields
  • Add translations to forms.替表單加翻譯
  • Attach forms to request types (manually or via automation).把表單附到 request type（手動或 automation）
  • Create shareable links.建立 shareable link
  • Manage the form preferences that affect how a form behaves.管理表單 preferences

3 分鐘速覽

Forms：比 request form 更靈活的表單

  1. 建立Space settings → Request management → Forms：從 200+ 個 template 或 blank 開始；要 Jira admin 或 project admin。
  2. 排版Confluence 風格編輯器：標題、bullets、表格、引用、多欄 layout。
  3. Sections＋條件邏輯依 radio、checkbox、dropdown 的答案顯示或隱藏 section；必填欄位不能放在條件 section。
  4. Linked Jira fieldsForm field 只存在表單裡；連到 Jira field 才能被 JQL、automation、報表使用。
  5. 放在哪Attach to request types、shareable link、加到既有 issue（含 automation 的 Attach forms）。
  6. Preferences保持開放可編輯、每次重送存 PDF、送出後鎖定（只有 admin 能改）、推薦給 agent。
建立

建立表單、section 與條件

  1. 新表單Forms → 選 template 或 Blank form；有多個 issue type 時先選這張表單要建立的 work 類型。
  2. 加內容從右側拖拉欄位；輸入 / 加元素（標題、表格、layout、bullets、quote）。
  3. Section把相關欄位包成 section；選 section → Create logic → Show／Hide → 條件（field、operator、value），可用 AND、OR。條件欄位要是 radio、checkbox、dropdown。
  4. 欄位行為每個欄位可設必填、驗證、說明、連到 Jira field；考綱另列 default response（預設回答），官方文件未詳述操作。
  5. Preview測試版面、條件與驗證，再 Save changes。編輯不會影響已經在 issue 上的表單實例。
本段必考
  • 條件 section 依 radio、checkbox、dropdown。
  • 必填欄位不能放在條件 section。
Linked Jira fields

Form field vs Jira field

Form fieldJira field（custom／system）
誰能建Project admin 在表單裡建，不用 Jira adminJira admin
存在哪只存在這張表單整個站台
JQL、automation、報表✗ 不能直接用✓
連結後兩邊同步：改 form field 會更新 Jira field，反之亦然
  • 連結規則：同一個 Jira field 不能同時在 request form 與表單上（會出現兩次）；同一張表單裡一個 Jira field 只能被連一次；兩邊類型要一致（多選不能連到文字）。
  • Approvers 欄位放進表單，customer 就能自己選 approver。
本段必考
  • 要給 JQL／automation／報表用 → 連到 Jira field。
放在哪

表單出現的地方

位置怎麼設說明
Request type 的 portal 表單Request type → Attach form；或 Form settings → Attach to request types出現在 Jira 欄位下方，customer 感覺是同一張表；送出後在 request 的 Forms 區
Shareable linkForm settings → Create a shareable link不經 portal 直接建 issue；可嵌到 Confluence；給 admin、agent、Service Desk Team 的 collaborator 使用
加到既有 issueAgent 在 issue 上 Add form（internal 或 external）；或 automation 的 Attach forms／Copy forms向 customer 補資料、記錄內部流程
不支援的管道

官方：forms 目前不能用在 email、chat、virtual agent、widget。

本段必考
  • Forms 不能用在 email、chat、widget、virtual agent。
Preferences 與翻譯

表單送出後的行為

Preference（送出時）效果
Keep this form open for edits任何人可以再編輯、重送
Save a PDF version each time it's resubmitted每次重送存一份 PDF，追蹤變更
Lock this form once submitted只有 project admin 能編輯或刪除（locked 狀態）
Show this form as recommendedAgent 在 issue 加表單時，它會排在清單最上面
Ignore field validation驗證不擋建立；要先開 Keep this form open for edits 才能開
表單狀態意思
Open for edits在 customer 手上填寫或修改，可存草稿
Submitted已送出；agent 可 Edit 或 Open customer edits
Locked只能檢視；只有 admin 能改
  • 翻譯：表單 Translate 分頁 → Add languages → 逐欄翻譯 → 開 Available to customers。沒有對應語言的 customer 看到 primary language。Portal 的 Language support 也要啟用該語言，否則不會出現。連到 Jira field 的選項欄位目前不能翻譯。
本段必考
  • Lock＝送出後只有 admin 能改。
  • 翻譯要開 Available to customers＋portal language support。
