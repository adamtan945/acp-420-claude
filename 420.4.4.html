Workflows 與 approvals

Approval 讓主管、資安、財務在 request 往下走之前把關。考你看懂 request type 用哪個 workflow，以及設定預設或由 customer 選擇的 approver。

3 分鐘速覽

Workflow 來自 issue type；approval 掛在 status 上

  1. 看 request type 用哪個 workflowRequest type → issue type → workflow scheme；Space settings → Workflows 可查看與編輯。
  2. Approval step 掛在 status該 status 至少要有 Approve 與 Decline 兩個 transition；加 approval 要 Jira admin。
  3. Approver 不用授權是 service project 的 customer 就能核准：portal、email、Slack、Teams。
  4. Approver 欄位User picker（multiple users）或 group picker（multiple groups）custom field，加到 request type。
  5. 預設 approver欄位勾 Use preset value and hide from portal，填固定的人或 group（Jira admin）。
  6. 讓 customer 選把 Approvers 欄位放進 request form；customer sharing 要選「space 或 organization 內搜尋」；customer 不能選 group。
Workflow

Request type 用哪個 workflow

  • Request type 對應 issue type，issue type 經由 workflow scheme 對應 workflow；所以「Request new hardware」與「Request new software」共用 Purchase issue type 時，workflow 一樣。
  • Space settings → Request types 列表會顯示每個 request type 的 workflow；Space settings → Workflows 可以看、可以（Jira admin）編輯。
  • Customer 在 portal 看到的是 Status name to show customer（420.4.1），不是 workflow 內部 status 名稱。
本段必考
  • Workflow 跟著 issue type，不跟 request type。
Approval

核准步驟的好處與設定

好處說明
流程可追溯誰、何時、核准或拒絕、留了什麼意見，都記在 request 上
Approver 不用授權Customer 身分就能核准，主管不必佔 agent 授權
Customer 看得到進度Portal 上顯示等待誰核准；customer 不用來回追問
自動轉 status核准或拒絕後自動走對應 transition，不用 agent 手動推
  1. 準備欄位建 user picker（multiple users）或 group picker（multiple groups）custom field，context 設為 Global，加到 request type。
  2. 編輯 workflow（Jira admin）Space settings → Workflows → Edit → Diagram → 選 status → 勾 Include approval step。
  3. 設定Number of approvers（幾個人要核准）→ Approver source（哪個欄位；也可用 affected services 的 change approvers）→ Approve／Decline 各轉到哪個 status → Exclude approvers from（例如排除 Reporter，避免自己核准自己）。
  4. PublishPublish draft。
本段必考
  • Approval 要 status 有 Approve 與 Decline 兩個 transition。
  • Exclude approvers 可防止 reporter 自己核准。

預設清單 vs customer 自己選

做法怎麼設Customer 看得到嗎
預設 approver（pre-set list）Request form 的 approver 欄位勾 Use preset value and hide from portal，填人或 group（Jira admin）看不到；agent 在 issue 上看得到
Customer 自己選把 Approvers 欄位（或 user picker multiple users）拖進 request form；可設 Required、改 Display name看得到；只能選個人，不能選 group
Affected servicesApprover source 選 Affected services，用 service 的 change approvers依 service 決定
Customer 選不到人？

讓 customer 選 approver 前，customer permissions 的 sharing 要設成 Customers can search for other customers within their space or organizations。

本段必考
  • 預設＝preset＋hide；自己選＝欄位放上表單。
  • Customer 只能選個人 approver。
