3 分鐘速覽

Portal＝一個 service project 的門面；help center＝所有 portal 的大廳

  1. 品牌Space settings → Channels & self service → Portal：portal 名稱、介紹文字、logo（JPEG／GIF／PNG，建議 50×50）；URL、banner、顏色從 help center 繼承。
  2. 公告Portal 頂端顯示公告；project admin 可勾「Yes, agents can add announcements to this portal」讓 agent 也能發。
  3. Help center 公告Jira admin 發；也可讓 agent 發。
  4. Portal groups把 request type 分組；超過一個 group 才會在 portal 顯示分組（見 420.4.1）。
  5. External resources最多 10 個外部連結，顯示在 portal 的 Related resources。
  6. Language support預設語言＋其他語言；翻譯 portal、request types、customer notifications、email templates、help center。

  • Add an announcement to a help center or portalSpace admins can add announcements to the portal or give permission to agents to do the same.
  • Add links to external resources in your service spaceYou can add up to 10 links and they’ll show up in your portal as Related resources.

Widget 與外部資源

在其他網站收單、連到外部資源

  • Widget：把提單入口嵌到任何你管理的網站。前提是 open portal；要在 widget 讀 KB，KB 的 Who can view 要設 Anyone。
  • Widget 的 default request type 不能有 widget 畫不出來的必填欄位，否則會顯示 request type 無效。修改 widget 會自動套用到所有嵌入的地方。
  • External resources：Channels & self service → External resources → Add link；最多 10 個，顯示為 Related resources，也會出現在 help center 搜尋結果。例子：VPN 教學影片、請假政策文件、Slack 頻道、其他系統的申請表。
本段必考
  • External resources 最多 10 個。
  • Widget 用 KB → KB 要開放給 Anyone。

語言

預設語言與翻譯

  1. 預設語言Space settings → Language support → 選 default language。建議與多數 customer 一致；customer 的偏好語言沒加入或被停用時，就看到預設語言。
  2. 加語言Language support → 加入其他語言並啟用。
  3. 翻譯內容Portal（名稱、公告、欄位名稱）、request types、customer notifications、email templates；help center 的名稱、首頁標題、公告、登入訊息。
  4. Customer 端依 customer 在 profile 設的語言顯示；form 的翻譯要另外在 form 的 Translate 分頁做（420.4.2）。
本段必考
  • Customer 看到哪個語言：偏好語言（有翻譯且啟用）→ 否則預設語言。

實作 Lab：替 portal 換門面、發公告、加外部連結

約 25 分鐘HELP 的 project admin（help center 的顏色、URL、公告要 Jira admin）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：改 portal 的名稱、介紹與 logo，讓 agent 能發公告，加一個外部資源連結，再加一種語言，從 customer 的視角逐一確認。

這個 Lab 對應的考點

Portal 名稱、介紹、logo 在 Portal 設定；URL、banner、顏色繼承 help center；agent 發 portal 公告要 project admin 開權限；external resources 最多 10 個；customer 看到偏好語言（有翻譯且啟用），否則看預設語言。

準備

  • 準備一張約 50×50 的 PNG 當 logo。
  • Cara 的瀏覽器開著 HELP portal。

步驟

  1. 你應該看到：Cara 看到新名稱、介紹文字與 logo。Logo 也會出現在之後寄給 customer 的通知信。
  2. 你應該看到：找不到：portal 的 URL、banner、按鈕與連結顏色繼承它所在的 help center，要到 help center 的 Customize 改。
  3. 你應該看到：通常 Leo 沒有發公告的入口：預設只有 project admin 能發 portal 公告。
  4. 你應該看到：Leo 能發公告了；Cara 重新整理，公告出現在 portal 頂端。
  5. 你應該看到：清單出現這個連結；Cara 的 portal 多了 Related resources 區塊。
  6. 你應該看到：語言清單多了這個語言，狀態是 customer 可見。
  7. 你應該看到：Cara 看到翻譯後的 request type 名稱；Dan 看到預設語言。沒有翻譯到的自訂內容，Cara 看到的仍是預設語言。
