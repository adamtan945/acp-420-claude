420.5.2・Customer Portal and Notifications 12%

Virtual agent

Virtual agent 在 portal、help center、Slack、Teams 先接住 customer 的問題。考你 intent、standard flows、default request type、AI answers 與對話分析。

考試佔 12%
官方考綱原文（這一節會考的範圍）
  • Set the virtual agent default request type.設定 virtual agent 的 default request type
  • Create Intents to represent a specific problem, question, or request that the virtual agent can help resolve.建立 intent
  • Modify text for Standard flows (Greet, Escalate, Resolve, Match intent, and Auto-close).修改 standard flows 的文字
  • Enable Atlassian Intelligence answers to utilize knowledge base articles to generate virtual agent responses.啟用 AI answers
  • Analyze the virtual agent's previous conversations.分析過去的對話

3 分鐘速覽

Virtual agent：用 intent 或 AI answers 先幫 customer 解決

  1. Intent一個特定問題或請求；有 name、display name、training phrases（至少 3 個）與 conversation flow。
  2. AI answers用 generative AI 搜尋連結的知識庫，摘要成回答並附來源文章。
  3. Default request typeVirtual agent 建 work item 時用；不能藏在 portal 外、不能有必填欄位。
  4. Standard flowsGreet、Match intent、Resolve（CSAT）、Auto-close（5 分鐘無動作）、Escalate、Offer options。
  5. Conversations 頁看 Matched／AI answered／Unassisted，Escalated／Resolved／Closed 與 CSAT。
  6. Intent 不支援 emailIntent 在 email 以外的 customer 管道都能用。
運作方式

一段對話怎麼走

IntentAI answers
怎麼回答照你設計的 conversation flow 一步一步走AI 摘要知識庫文章
適合要來回問答、收集資訊、導到正確 request type、執行動作（web request、automation）看文章就能解決的問題
前提建 intent、訓練句、flow知識庫要即時正確；AI 要啟用
控制程度高：每句話都由你決定較低：AI 生成
本段必考
  • 要控制每一句話 → intent；知識庫好就快上線 → AI answers。
設定

Default request type、intent、standard flows

  1. 位置Space settings → Channels & self service → Virtual service agent → Manage in Studio。
  2. Default request typeIdentity → Jira Service Management settings → Default request type。不能藏在 portal（自動建立失敗時會給 customer 表單連結）、不能有必填欄位（virtual agent 填不了）。
  3. 建 intent（project admin）Intents → Add intent → 選 template 或 Start from scratch → Name、Description、Display name（customer 看得到的選項名稱）→ 3 個 training phrases → 建 conversation flow。建好先在 test mode 測，再對 customer 啟用。
  4. Conversation flow 步驟傳訊息、問問題、Ask for information、Change request type and fields（覆蓋預設 request type）、Run automation、web request、結束分支。
  5. Standard flows 文字可改 Greet（留空＝關閉）、Escalate、Offer options（1–3 個選項：Raise a request、See search results、Ask another way）等訊息。
  6. AI answers在 Studio 啟用 AI answers，讓 virtual agent 用連結的 KB 回答。
Standard flow何時做什麼
GreetCustomer 第一句話打招呼；同時比對 intent
Match intent第一句話確認 intent、列出多個 intent 的 display name、或用 AI answers 回答、或請 customer 換句話說
Resolve（with CSAT）Customer 說已解決結束並請 customer 打 1–5 分
Auto-close5 分鐘沒動作問「還需要幫忙嗎？」；選 No 或再 24 小時沒回 → 依是否曾比對到 intent／AI 答過，記為 Resolved 或 Closed
Escalate需要人告知已建 request，用 default request type 建 work item
Offer options連續兩次要求換句話說、AI 回答沒幫到給 1–3 個按鈕選項
本段必考
  • Default request type：不能隱藏、不能有必填欄位。
  • Display name＝customer 看到的 intent 選項。

CSAT1–5Customer 滿意度
  • Escalated 多又 Matched → 改善該 intent 的 flow 或 training phrases。
  • AI answered 但 CSAT 低或常 escalate → 知識庫過時，更新文章。
  • Unassisted 多 → 缺 intent，新增 intent 並用 Change request type 步驟分流。
本段必考
  • Unassisted 多＝缺 intent；AI 答了還 escalate＝KB 要更新。
