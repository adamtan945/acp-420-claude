知識庫連結與權限

知識庫讓 customer 自助解決問題。考你連結與取消連結 Confluence，以及「誰能看、誰能寫」的設定與限制。

3 分鐘速覽

知識庫＝連到 service project 的 Confluence 內容

  1. 連結Space settings → Channels & self service → Knowledge base → Set up knowledge base／Add knowledge：可連 space、folder 或 page（含所有子頁）。
  2. 取消連結Unlink：只從 service project 移除，Confluence 裡的 space 還在。
  3. Who can viewAnyone（不登入、會被搜尋引擎找到）／All logged-in users／Only Confluence users。
  4. Who can editService space users（agent、admin 可在 JSM 寫文章）／Only Confluence users。
  5. Site 設定先決定選項Jira admin 在 Products → JSM → Knowledge base permissions 開 All logged-in users、Anyone；沒開，project admin 就選不到。
  6. Internal vs externalExternal 給 customer（portal、help center、virtual agent）；internal 只給 agent。
連結

連結與取消連結 Confluence

  1. 第一次Knowledge base → Set up knowledge base → 選 space、folder 或 page → Link。
  2. 加更多Add knowledge → 選內容 → Link。已經連了整個 space，就不用再加其中的 page；只想要某個 folder，要先 unlink 整個 space。
  3. 出現在哪Knowledge base 的 Articles 清單、portal 與 help center 搜尋結果、virtual agent 的推薦答案。
  4. 取消Knowledge base → 選 space → Unlink → Confirm；可多選一次 unlink。Space 仍在 Confluence。
本段必考
  • 連 page 或 folder 會帶入所有子頁。
  • Unlink 不會刪 Confluence 內容。
權限

誰能看、誰能寫

Who can view誰看得到前提
Anyone網路上任何人，不用登入；會被 Google 搜到Site 開 Anyone；Confluence 付費方案（Standard 以上）；portal 要公開（anyone can send a request）
All logged-in users登入 service project 或 help center 的人（含 customer）Site 開 All logged-in users
Only Confluence users有 Confluence 授權、能存取該 space 的人永遠可選
Who can edit誰能寫
Service space usersAgent 與 admin 能在 JSM 建立、編輯文章
Only Confluence users只有有 Confluence 授權的人；細部權限在 Confluence 管
改不了 Who can view？

Confluence 的全域權限（例如 anonymous access 的 View）與 KB 設定衝突時會鎖住選項；到 Confluence space settings 開或關 Anonymous access 的 View。

自我檢查：先在心裡回答，再點開對答案
Q1Project admin 想把文章設成 Anyone，但下拉選單沒有 Anyone。可能原因？看答案
Site 層 Knowledge base permissions 沒開 Anyone、Confluence 是 Free 方案、或 portal 不是公開的。
本段必考
  • Anyone＝全網公開、要 site 開＋Confluence 付費＋公開 portal。
  • 進階權限只能在 Confluence 改。
Internal vs external

給 agent 的與給 customer 的

External knowledge baseInternal knowledge base
給誰Customer：portal、help center、virtual agentAgent：service project 的 Knowledge base 頁
內容FAQ、how-to、自助排錯Runbook、SOP、敏感排錯步驟
沒有的功能—草稿、分類、給無 Confluence 授權者、在 KB 設定管權限、從 JSM 建立文章
需要—Confluence 授權
本段必考
  • Internal 只給 agent、需要 Confluence 授權。
