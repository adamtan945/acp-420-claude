3 分鐘速覽

在 customer 提單時推薦對的文章

  1. Article suggestionsKnowledge base 設定 → Control article suggestions → 對每個 request form 開 Allow suggestions?。
  2. Labels 限縮Only show articles labeled：只推薦有特定 label 的文章，例如 vpn、password。
  3. 何時出現Customer 在 Summary 欄位打字時。
  4. 限制知識庫連到其他 Confluence site 時，portal 不會顯示 article suggestions。
  5. Agent 也能分享在 issue view 用知識庫面板把文章回覆給 customer。
  6. 看成效KB 報表：文章被看了多少、解決了多少 request（420.7.2）。

建議文章

依 request type 推薦文章

  • 建議 label 取跟 request form 相近的名字（VPN access → vpn），寫文章的 agent 才記得要加。
  • 文章要被推薦，還要 customer 有權限看（Who can view）。
  • Agent 在 issue view 可以從知識庫面板搜尋並把文章分享給 customer；也能從 request 直接建立新文章（external KB、Who can edit＝Service space users 時）。
考題長相

「VPN 的 request 表單老是推薦到印表機文章」→ 開 article suggestions，並設 Only show articles labeled = vpn，再替 VPN 文章加 label。

本段必考
  • Suggestions 逐 request form 開。
  • 用 label 限縮推薦範圍。
  • 跨 site 的 KB 不顯示 suggestions。

動手做

實作 Lab：讓 VPN 表單只推薦 VPN 文章

約 20 分鐘HELP 的 project admin；Help KB 已連結（420.6.1）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：對單一 request form 開 article suggestions，用 label 把推薦範圍縮小，再看 KB 報表怎麼記錄 deflection。

這個 Lab 對應的考點

Article suggestions 逐 request form 開；Only show articles labeled 用 label 限縮；customer 在 Summary 打字時出現；知識庫連到其他 Confluence site 時 portal 不顯示 suggestions。

準備

  • Help KB 有兩篇文章，標題都含「連線」：VPN 連線失敗怎麼辦（label vpn）、印表機連線失敗（沒有 label）。
  • Help KB 的 Who can view 是 All logged-in users（Cara 看得到）。

步驟

  1. 你應該看到：Get IT help 的 Allow suggestions 已開；其他 request form 不受影響。
  2. 你應該看到：Summary 下方出現建議文章，兩篇都可能出現。
  3. 你應該看到：只剩「VPN 連線失敗怎麼辦」：label 讓推薦更精準。
  4. 你應該看到：沒有建議文章：suggestions 是逐 request form 開的。
  5. 你應該看到：這會被算成一次 Requests deflected（報表通常要稍後才反映）。
  6. 你應該看到：Cara 收到附文章連結的回覆。留言裡有 KB 文章連結的已解決 request，會算進 Requests resolved 的「with an article」。
  7. 你應該看到：看得到剛才的操作（若還沒出現，隔一段時間再看）。

試試看：改一個設定，觀察差異

T1把「VPN 連線失敗怎麼辦」的 vpn label 拿掉，Cara 再打一次。看結果
Get IT help 不再推薦它：沒有 label 就不符合 Only show articles labeled。做完把 label 加回。
T2把 Help KB 的 Who can view 改成 Only Confluence users，Cara 再打一次。看結果
通常不再有建議：文章要被推薦，customer 也得有權限看。做完改回 All logged-in users。
T3（想像，不實際做）知識庫改連另一個 Confluence site 的 space。看結果
Portal 不會顯示 article suggestions。
心像錨點：閉上眼睛想一次這個畫面

Control article suggestions 表格：Get IT help 那一列 Allow suggestions 是開的，旁邊 Only show articles labeled 寫著 vpn。逐表開、用標籤縮。

收尾

  • Get IT help 的 label 清空；不需要時把 Allow suggestions 關掉。
  • 保留兩篇文章與 vpn label，之後複習可再用。
