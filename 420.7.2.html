3 分鐘速覽

Reports 頁：default 不能改、custom 自己組 series

  1. Default reports（不能改）Workload、Satisfaction、Requests deflected、Requests resolved。
  2. Custom reports（可改、可新建）Created vs resolved、Time to resolution、SLA met vs breached、SLA success rate…；project admin 建立。
  3. Series一組資料點：選 metric、label、顏色、Filter by（work type、status、priority、component 或 JQL）；最多 20 個。
  4. CSATRequest settings → Customer satisfaction：預設開啟；status 進入 Done 類別就寄問卷（即使沒設 resolution）。
  5. DashboardService project report gadget 把多個 project 的報表放在一起。
  6. KB 報表Requests deflected（文章幫到忙）與 Requests resolved（有／無文章）。
資料來源（5）有疑慮時點開看官方原文
  • What are default reports?These reports can’t be changed, but provide valuable information for easily checking how your team are meeting their service level agreements (SLAs).
  • What are custom reports?You can edit an existing custom report or create your own new custom report.
  • Create a new custom reportIf desired, select Add series and repeat steps 4–8 to add up to 20 series.
  • About customer satisfaction (CSAT) surveysCustomer satisfaction (CSAT) surveys are triggered when the status of a work item moves to a Done status category, even if the resolution field is not set.
  • Add reports to a dashboardIf you work in multiple service spaces, you can add gadgets to a dashboard to view reports from those service spaces in one place.

Custom series

自己組報表

  1. 新報表Reports → New report → 名稱（project admin）。
  2. Add seriesSeries：選 metric（Created、Resolved、SLA met、SLA breached、Time to resolution…）→ Label → Color。
  3. Filter by依 work type、status、priority、component；或 Switch to JQL。
  4. 更多 series重複加，最多 20 個；再 Create。
考題長相

本段必考

  • 最多 20 個 series。

CSAT 與 dashboard

客戶滿意度與跨 project 儀表板

  • CSAT：Space settings → Request management → Customer satisfaction → Collect customer satisfaction feedback；可改問題文字。新 project 預設開啟。
  • Work item 進入 Done 類別的 status 時寄出（在 resolved 通知信裡），即使 resolution 沒設；只想在有 resolution 時寄，要調整 workflow 與 customer notification。
  • Customer 打 1–5 分並可留言；結果看 Satisfaction 報表。有 Slack chat 時也能在 Slack 回饋。
  • Dashboard：Edit dashboard → Add gadget → Service project report（建立此 gadget 要 Jira admin）；也可用 Filter results、Pie chart、Created vs resolved 等一般 gadget 搭配 JSM 的 filter。
  • 用報表調設定：SLA 常違約 → 調 goal、calendar 或增加人力、改 queue 排序；CSAT 低 → 看回饋、改 canned responses 與流程；Deflection 低 → 補寫文章、開 article suggestions。
本段必考
  • CSAT 由 Done 類別觸發，不看 resolution。

動手做

實作 Lab：做一張 Acme vs 其他的趨勢報表

約 25 分鐘HELP 的 project admin（custom report）；Jira admin（Service space report gadget）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：分清 default 與 custom report，自己組兩個 series 的報表，打開 CSAT 讓 Cara 打分數，再把報表放上 dashboard。

這個 Lab 對應的考點

Default reports（Workload、Satisfaction、Requests deflected、Requests resolved）不能改；custom report 由 project admin 建，series＝metric＋label＋color＋filter，最多 20 個；CSAT 在 status 進入 Done 類別時寄，即使沒設 resolution。

準備

  • HELP 有 Cara 與 Dan 各提的幾張 request，其中有幾張已解決。

步驟

  1. 你應該看到：這兩張是 default report，沒有編輯或加 series 的選項。
  2. 你應該看到：它由兩個 series 組成（Created、Resolved），可以改、可以加。看完不存。
  3. 你應該看到：報表出現第一條線。
  4. 你應該看到：兩條線並列；Label 顯示在報表名稱下方。一張報表最多 20 個 series。
  5. 你應該看到：問題文字更新。新 project 預設就是開的。
  6. 你應該看到：信裡附有新的問題文字與評分；送出後 Satisfaction 報表出現這筆分數與意見。
  7. 你應該看到：Dashboard 上出現這張報表；你可以再加其他 service space 的報表，集中在一頁看。
  8. 你應該看到：例如：違約多 → 調 SLA goal、calendar 或 queue 排序；CSAT 低 → 看意見、改 canned responses；deflected 少 → 補文章、開 article suggestions。
