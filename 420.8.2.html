3 分鐘速覽

Trigger → condition → action（＋branch）

  1. 建立Space settings → Automation → Create rule（自己組，或從 template、或用 AI 描述產生）。
  2. JSM triggersApproval required、Approval completed、Object created／updated／deleted（global）、SLA threshold breached、Form submitted。
  3. JSM conditionsAffected services、Forms attached、AQL。
  4. JSM actionsApprove/decline request、Add service project customer、Create incident、Create work item with a request type、Edit request type、Lookup／Create／Edit object、Attach forms、Copy forms。
  5. Smart values{{issue.summary}}、{{now.plusBusinessDays(3)}}、{{issue.labels.join(", ")}}、{{#=}}…{{/}}、Create variable。
  6. 管理Enable／disable、labels 分類、rule details（owner、actor、scope）。

JSM 專屬元件

考綱列出的 trigger、condition、action

類型元件用途與限制
TriggerApproval required／Approval completed需要核准時通知 approver；核准或拒絕後轉 status、通知 customer
TriggerObject created／updated／deletedAssets object 變動時；只能用在 global rule
TriggerSLA threshold breached選 SLA 與「違約前／後多久」；提醒、升級 priority
TriggerForm submitted表單送出時（form 相關步驟只能在 project rule）
ConditionAffected services依 service tier、名稱、依賴服務判斷（ITSM project）
ConditionForms attached檢查是否附了某些表單、表單狀態
ConditionAQLAssets object 或 issue 的 Assets 欄位是否符合 AQL
ActionApprove/decline request自動核准低金額、標準變更
ActionAdd service project customer把 email 加成 customer（可放進 organization）；連續呼叫可能要加 Delay
ActionCreate incident建立指定 request type 的 incident；可避免重複建立
ActionCreate work item with a request type用 request type 建單；隱藏欄位不支援
ActionEdit request type改 request type；新 request type 要對應同一個 issue type，否則錯誤
ActionLookup objects／Create object／Edit objectAQL 查最多 100 個 object（{{lookupObjects}}）；建立 object；Edit object 只在 global rule 且 object 是焦點時
ActionAttach forms／Copy forms附表單、從其他 work item 複製表單；只能 project rule
本段必考
  • Object trigger 只能 global。
  • Form 元件只能 project rule。
  • Edit request type 要同一個 issue type。

管理

啟用、停用、標籤

  • Rule 清單的開關可以 Enable／Disable；停用的 rule 不會觸發，但設定保留。
  • Labels：Automation 頁 Add label（名稱、顏色）→ 把 rule 拖到 label 上；可依 label 篩選。Global 與 project rule 共用 label。
  • Rule details：Name、Description、Owner（錯誤時收 email）、Notify on error、Who can edit（Private／Specific admins／All admins）。
  • Rule settings：Allow rule trigger（能否被其他 rule 觸發）、Scope、Actor。
本段必考
  • Labels 只是分類，不影響執行。
易錯觀念

考題愛用的錯誤說法

Object created trigger 可以用在 project rule。
Object trigger 只能用在 global rule。
官方來源
Attach forms 可以設定成 global rule。
Form 相關步驟只能在 project rule。
官方來源
Edit request type 可以換成任何 request type。
新 request type 要對應同一個 issue type，否則 audit log 出錯。
官方來源
一條 rule 可以有兩個 trigger。
只能一個；多個事件用 Multiple work item events trigger。
官方來源
Lookup objects 可以回傳無限多個 object。
最多 100 個。
